Manual de Uso - Sistema La Michoacana

Guía técnica y funcional para el uso del sistema de gestión

Bienvenido

Este manual está diseñado para guiar al usuario en el uso del sistema de gestión La Michoacana, una aplicación desarrollada para optimizar la administración de productos, ventas y reportes dentro de una heladería o paletería local.

Objetivo del sistema

El objetivo principal de este sistema es ofrecer una herramienta práctica y sencilla para la gestión interna de una sucursal de La Michoacana, permitiendo controlar el inventario de productos, registrar ventas y consultar reportes de desempeño.

Objetivos específicos

  • Facilitar el registro y actualización de productos.
  • Controlar de manera eficiente las ventas diarias.
  • Generar reportes automáticos para un mejor análisis de desempeño.
  • Mejorar la experiencia del usuario con una interfaz moderna y atractiva.
  • Reducir errores humanos mediante validaciones y procesos automatizados.

Recomendaciones de uso

Utiliza los botones de navegación en la parte superior para acceder a los distintos módulos del sistema. Cada sección te mostrará información detallada sobre su funcionamiento.

Versión 1.0 — Actualizado en Octubre 2025

Módulo de Productos

El módulo Productos permite gestionar los artículos disponibles en la heladería, como paletas, nieves, aguas, toppings o cualquier otro producto ofrecido al cliente. Desde esta sección podrás registrar, editar y consultar productos de manera sencilla.

Objetivo del módulo

Mantener un control preciso del inventario de productos, garantizando que la información del catálogo esté siempre actualizada y accesible para el personal autorizado.

Funcionalidades principales

  • Agregar producto: Permite registrar un nuevo producto indicando su nombre, precio y categoría.
  • Modificar producto: Edita los datos de un producto ya existente.
  • Buscar producto: Localiza rápidamente un artículo mediante filtros de búsqueda.

Recomendaciones

  • Evita dejar campos vacíos al registrar un producto.
  • Usa nombres claros y específicos (por ejemplo: “Paleta de mango con chile”).
  • Verifica los precios antes de guardar los cambios.
  • Si eliminas un producto, asegúrate de que no esté en uso en alguna venta activa.

Módulo de Ventas

El módulo Ventas permite registrar las transacciones realizadas con los clientes, así como calcular subtotales, impuestos y totales finales. Este apartado garantiza un control ordenado y transparente de las operaciones diarias de la heladería.

Objetivo del módulo

Facilitar el proceso de venta, permitiendo al personal registrar productos vendidos, calcular el monto total y generar comprobantes, manteniendo una trazabilidad completa de cada operación.

Funcionalidades principales

  • Registrar venta: Agregar productos al carrito, indicar cantidades y aplicar descuentos.
  • Calcular totales: El sistema calcula automáticamente el total a pagar.
  • Historial de ventas: Consultar transacciones pasadas filtrando por fecha o cliente.

Ejemplo de flujo de venta

  1. El usuario selecciona los productos que el cliente desea comprar.
  2. Se muestran los precios y cantidades en una lista.
  3. El sistema calcula automáticamente el total.
  4. El usuario elige el método de pago y confirma la venta.
  5. El comprobante se genera y la venta queda registrada en la base de datos.

💡 Recomendaciones

  • Verifica que los precios de los productos estén actualizados antes de registrar la venta.
  • Confirma el método de pago antes de finalizar la operación.
  • Evita cerrar la ventana del sistema mientras se procesa una venta.
  • Consulta el historial de ventas regularmente para llevar un control diario.

Módulo de Reportes

El módulo Reportes es una herramienta clave para el análisis y la toma de decisiones dentro del sistema de administración de La Michoacana. Permite visualizar y exportar información detallada sobre las ventas, productos y desempeño general del negocio.

Objetivo del módulo

Brindar una visión clara y estructurada de los resultados obtenidos en distintos periodos de tiempo, ayudando a identificar patrones de consumo, productos más vendidos y áreas de mejora.

Funcionalidades principales

  • Reporte diario: Muestra las ventas realizadas durante el día actual, con totales y desglose por producto.
  • Reporte semanal: Resume las ventas de los últimos siete días y compara el rendimiento con la semana anterior.
  • Reporte mensual: Proporciona una visión general de ingresos, productos más vendidos y frecuencia de clientes.
  • Exportación: Permite exportar los reportes en formatos PDF o Excel para su análisis externo.
  • Gráficas dinámicas: Representa visualmente los datos mediante barras o gráficos circulares.

Cómo interpretar los datos

  1. Observa las variaciones en ventas diarias y semanales para detectar tendencias.
  2. Identifica los productos con mayor margen de ganancia.
  3. Evalúa las horas pico de venta para mejorar la atención al cliente.
  4. Utiliza los reportes históricos para planificar promociones o cambios de inventario.

Recomendaciones

  • Genera un reporte diario al cierre de cada jornada.
  • Guarda copias de los reportes exportados en un respaldo externo.
  • Analiza semanalmente los productos menos vendidos para ajustar la producción.
  • Utiliza los gráficos para detectar oportunidades de crecimiento.
